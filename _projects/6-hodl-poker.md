Poker on TRON network.

dApp Poker game for 2 people using TRON as an value exchange intermediary. 
Financial transactions are powered by smart contracts with a thin NodeJs backend to control game flow.

**Tech stack:**
- *Node.js*
- *React Redux*
- *TRON*
- *Solidity*
- *CircleCi*
- *Heroku*
